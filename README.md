# 计算机视觉期末刷题助手

一个用于计算机视觉期末复习的纯静态刷题网页，包含单选题、填空题、判断题和编程题。

## 在线使用

GitHub Pages 部署完成后，可直接打开：

<https://qzjjimmy.github.io/cv-final-review/>

无需安装软件或登录，打开网页即可按题型筛选、随机抽题、查看答案和解析。

## 本地运行

直接双击 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 功能

- 按题型筛选题目
- 前后切换、随机抽题、键盘方向键切题
- 显示当前题目答案和解析
- 查看当前题型的全部答案

## 分享

将仓库或在线页面地址发送给同学即可。页面不依赖后端服务，所有题目数据都包含在 `index.html` 中。
